# Boundary inputs

`wb_boundaries_geojson_lowres.zip` is the World Bank Official Administrative Boundaries low-resolution GeoJSON archive downloaded from the World Bank Data Catalog.

Source: <https://datacatalogfiles.worldbank.org/ddh-published/0038272/DR0046667/wb_boundaries_geojson_lowres.zip>

The World Bank archive does not include a separately coded Taiwan polygon. `taiwan.geojson` is the small supplemental polygon used by the referenced VisQuill demographic map so BACI's documented `S19` proxy can remain selectable. Taiwan is presented separately for data availability; this does not imply a position on political status.

Reference: <https://visquill.com/gallery/world-demographics/>

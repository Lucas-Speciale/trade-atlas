# Natural Earth supplemental geometry

`taiwan.geojson` is the Taiwan feature extracted from Natural Earth's 1:110m Admin 0 map-units GeoJSON dataset.

Source: <https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_map_units.geojson>

Natural Earth vector data is in the public domain. The feature properties are reduced to the identifiers expected by the Trade Atlas build. Its inclusion supports BACI's documented `S19` proxy and does not imply a position on political status.
